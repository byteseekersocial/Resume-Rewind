# Resume Rewind

A Jellyfin plugin that automatically rewinds playback when resuming movies and TV episodes.

## Features

- Automatic rewind when resuming playback.
- Separate movie and episode settings.
- Administrator defaults and individual user preferences.
- Configurable rewind duration (0–60 seconds).
- Individual preferences can be reset to administrator defaults.
- Server-side functionality without requiring client modifications.
