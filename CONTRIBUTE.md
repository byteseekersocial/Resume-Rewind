
# Contributing to Resume Rewind

First off, thank you for considering contributing to Resume Rewind!

Resume Rewind is a personal, community-driven project created because I couldn't find an existing solution that did exactly what I wanted. The goal is to make resuming movies and TV episodes a better experience for everyone using Jellyfin.

Contributions, suggestions, bug reports, and feedback are always welcome!

## Getting Started

If you're interested in contributing, here are a few ways you can help:

- Report bugs or unexpected behavior.
- Suggest new features or improvements.
- Help test the plugin on different Jellyfin clients and platforms.
- Improve documentation.
- Submit code changes and bug fixes.
- Help expand compatibility with additional Jellyfin clients.

## Reporting Bugs

Before reporting a bug:

1. Check the existing [Issues](https://github.com/byteseekersocial/Resume-Rewind/issues) to avoid duplicates.
2. Make sure you're using the latest available version.
3. Include your Jellyfin Server version, plugin version, and client platform.
4. Provide steps to reproduce the issue whenever possible.

Please use the Bug Report issue template when submitting a bug.

## Suggesting Features

Have an idea that could make Resume Rewind better?

We'd love to hear it!

Open a Feature Request through the GitHub Issues tab. Explain what you'd like to see, why it would be useful, and how you imagine it working.

## Contributing Code

Want to work directly on the project? You're welcome to!

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your changes and test them.
4. Commit and push your changes to your fork.
5. Open a Pull Request describing what you changed and why.

Please keep contributions focused and avoid unrelated changes in the same Pull Request.

## Testing

Resume Rewind currently has confirmed client-side functionality on:

- Jellyfin Web
- Jellyfin for iOS
- Roku

Testing on additional clients is especially appreciated!

If you're making changes, please test them on the clients your changes affect whenever possible. Include your testing results in your Pull Request.

## Need Help or Want to Become a Contributor?

You don't have to be an experienced developer to get involved!

If you're interested in helping, have questions, or want to become a contributor, feel free to reach out.

You can contact me through GitHub or open an issue to get the conversation started.

## Thank You!

Resume Rewind is a community-based project, and every contribution helps make it better.

Whether you're reporting a bug, suggesting an idea, testing a new platform, or contributing code, your help is appreciated.

**Thanks for being part of Resume Rewind!**
