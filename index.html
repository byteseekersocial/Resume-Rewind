UP AND RUNNING IN MINUTES

Get back to watching.

Add the plugin repository to Jellyfin, install Resume Rewind, and configure it from your dashboard.

01

Open your Jellyfin Dashboard

Go to Plugins → Repositories.

02

Add the plugin repository

Give it a name such as Resume Rewind and paste the manifest URL.

03

Install and restart

Refresh the catalog, install Resume Rewind, then restart your server.

04

Set your rewind preferences

Open the plugin configuration and choose your movie and episode settings.
